# Datenschutzhinweise – Entwurf für die native App

Vor Veröffentlichung auszufüllen: Name/Firma, ladungsfähige Anschrift und Kontakt-E-Mail des Verantwortlichen. Eine öffentliche Datenschutz-URL muss durch den Herausgeber bereitgestellt werden.

Die native App Schlafwald verarbeitet kein Kinderprofil und benötigt keine Registrierung. Sie enthält keine Werbung, Analyse- oder Tracking-SDKs. Sie greift nicht auf Kamera, Mikrofon, Standort oder Kontakte zu. Erzählerdateien und 3D-Inhalte sind im App-Paket enthalten.

Auf dem Gerät werden Lautstärken, Dauer-/Bildoptionen, Tierauswahl und die Kennungen der in dieser Nacht bereits schlafenden Tiere mit einem lokalen Zeitstempel gespeichert. Der Zeitstempel ermöglicht das Fortsetzen einer unvollendeten Nacht innerhalb von 90 Minuten. Diese Angaben werden von der App nicht an einen Server übertragen. Beim Löschen der App werden sie entfernt; Android-Cloud-Backup ist deaktiviert.

Die im Browser bereitgestellte private Entwicklervorschau ist davon zu unterscheiden: Zum Laden und zur Zugriffskontrolle besteht eine Verbindung zum Hostingdienst. Dabei können technische Verbindungs- und Anmeldedaten nach den Datenschutzregeln des Dienstes verarbeitet werden. Die Vorschau ist keine anonyme native Offline-App.

Die Angaben zur nativen App müssen vor dem Release durch Prüfung des erzeugten Manifests, der enthaltenen Abhängigkeiten und eines Netzwerkmitschnitts bestätigt werden. Die Datenschutzerklärung muss dann an das tatsächlich veröffentlichte Paket angepasst werden.
